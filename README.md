# Eagle Logic Homebrew Tap

Homebrew formulae for [Eagle Logic](https://github.com/Eagle-Logic) tools.

## Install

```sh
brew install eagle-logic/tap/ctx
```

`ctx` is a queryable code graph for coding agents — call graphs, blast radius,
breaking-change gates, and cross-language port parity.
See [Eagle-Logic/context](https://github.com/Eagle-Logic/context).

## Note

Formulae here are published automatically by the release workflow in each
source repository. Edits made by hand will be overwritten on the next release.
